## 怎样读结果

- **工具已实现**：有脚本或测试，不代表故障已经跑过。
- **运行通过**：必须同时给出版本、范围、命令、退出码和证据目录。
- **历史报告通过**：原报告记录为通过，当前审查没有取得或重跑原始证据。
- **待验证 / 受阻**：缺少环境、注入器或原始记录，不能计为通过。

演练无法穷尽所有故障。单 broker 断连、三 broker 重启、跨版本升级、旧 FS 模块及云厂商发布，是不同的验证范围。相同错误码也不等于相同根因。
